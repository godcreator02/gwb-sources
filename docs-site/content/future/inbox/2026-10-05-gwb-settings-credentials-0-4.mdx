---
title: 跟进 settings 0.4 的每 home 凭据机制
description: 来源：gwb-base-plugins 凭据机制与 default 整体适配
---

settings 0.4 将 secret 值迁入每个 home 的 credentials.json。settings.all/get/set/delete 只处理普通设置；凭据管理经 credentials.list/status/copy/import/generate/delete，不回显值。插件内部 ctx.gwbSettings 的 define/get/set/delete 签名保持不变。

Sources 应以每个来源独立的 secret 槽替代新的 Windows 凭据写入；旧引用只显式复制到选定 home，保留地址和用户名绑定。适配后将 settings peer 跟至 ^0.4.0，验证迁移、删除后不复活与 home 隔离，在 default 整套切换前完成配套发版。
